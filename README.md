# RaahSafe DI Khan — React Frontend Concept

Interactive Vite + React implementation of the “Interactive City Journey” layout.

## Included interactions
- Responsive sticky navigation
- Interactive hero phone mockup
- Route mode comparison (recommended vs direct / affected)
- Official-alert affected-area reveal
- Comic / graphical-novel page sequence for routing, alerts, community reporting, and emergency mode
- Community report form that adds new reports to the feed
- Helpful counters on reports
- Emergency-mode simulation with staged location sharing
- Real-incident placeholder cards and “how the platform could help” framing
- Responsive mobile layout

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Notes
- This is a frontend concept prototype; it does not connect to real emergency services, authorities, or live map data.
- Replace demo incident cards with carefully sourced real examples before presenting them as factual content.
- The routing demo intentionally distinguishes verified alerts from community reports.
